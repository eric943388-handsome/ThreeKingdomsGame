# 三國養成遊戲 (Three Kingdoms Game)

一款基於瀏覽器的三國題材養成策略遊戲。

## 遊戲特色

- **資源管理**：發展金幣、糧食、石材，壯大你的勢力
- **武將招募**：從普通池和高級池招募三國武將
- **戰鬥系統**：尋找敵人並發動攻戰
- **武將養成**：使用道具提升武將等級、忠誠度和生命值

## 如何開始

在瀏覽器中打開 `ThreeKingdomsGame/index.html` 即可開始遊戲。

## 遊戲頁面

| 頁面 | 功能 |
|------|------|
| 發展 | 提升兵力和國防 |
| 招募 | 招募武將（普通/高級） |
| 攻打 | 尋找並攻擊敵人 |
| 武將 | 查看和管理你的武將 |
| 商店 | 購買資源和道具 |

## 資源說明

- **💰 金幣**：用於購買資源和普通招募
- **🍚 糧食**：戰鬥消耗資源
- **🪨 石頭**：建設發展資源
- **💎 高級武將卷**：用於高級招募

## 道具說明

- **🧪 補包**：恢復武將生命值
- **🎖 封侯令**：提升武將忠誠度
- **📦 經驗包**：提升武將經驗值

## 技術栈

- 原生 JavaScript (ES6+)
- HTML5 + CSS3
- 無需構建工具，直接在瀏覽器運行
